# Kingblack Nutrición

Dashboard para armar el informe de asesoramiento nutricional: datos del cliente con IMC automático,
platos de almuerzo y cena como gráficos con % por grupo de alimentos, pautas, indicaciones y los
modelos de plato de la Lic. Girgenti (con ejemplos completos). Descarga un PDF para subir a EVO.

## Publicado en GitHub Pages

https://kingblackgym-prog.github.io/nutricion/

Para publicar un cambio: editar `public/index.html`, correr `npm run build` (regenera `docs/index.html`,
un solo archivo con el logo incluido) y hacer commit + push a `main`. Los datos de los clientes no se
suben a ningún lado: quedan solo en el navegador de quien usa el dashboard.

## Versión local

```
npm start
```

Abrir http://localhost:3100
